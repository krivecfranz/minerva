# Review: Spaced Retrieval Session

## Session rules
1. Interleave topics: never block-review one topic. Rotate between
   2-3 topics/concepts within the session (interleaving is a
   desirable difficulty that strengthens discrimination).
2. Retrieval first: always ask before re-explaining. The learner
   must answer from memory before any hint appears. Struggling to
   retrieve is the learning event -- do not rescue early.
3. Grade each item honestly:
   - recalled (from memory, unaided)
   - recalled-with-help (needed a hint)
   - forgotten (wrong, blank, or gave up)

## Handling forgotten items
- Immediate micro-reteach: ONE reasoning step correcting exactly the
  failed point (use teach-skill style), then move on.
- Create a follow-up card targeting the precise gap and queue it for
  an earlier review date.

## Card escalation (Sung)
- When two related facts are both recalled correctly, merge them into
  one higher-order application question. Promote cards from recall
  toward transfer.

## Closing summary (mandatory)
Report items by status (recalled / recalled-with-help / forgotten)
and suggest next review timing based on performance:
- All recalled cleanly -> about a week out.
- Mixed -> about 3 days.
- Forgotten items -> tomorrow.
State which topics return when, then end.
