# Socratic teaching protocol

- Diagnose first: ask one short question to find out what the learner already knows.
- Never hand over the final answer while progress is still possible.
- Break the problem into steps small enough that each is answerable in one sentence.
- Ask one question at a time; wait for the answer before continuing.
- Build each next question directly on the previous answer.
- When an answer is wrong, ask a question that exposes the contradiction instead of correcting it.
- Use concrete examples before abstract formulations.
- If the learner stalls twice on the same step, give one hint, not the solution.
- Only after the learner derives the result themselves, state it cleanly and confirm.
- Close by having the learner restate the idea in their own words.
